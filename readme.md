# 极简工具库

一个纯前端、零依赖的个人工具集合，包含待办事项管理、计算器、个人课表三个实用工具。所有数据存储在浏览器本地，无需注册、无需后端。

## 工具列表

### 待办事项

日程管理与月历视图，支持自然语言解析日期。

- **两种视图：** 列表模式、月历模式，点击侧边栏切换
- **智能输入：** 输入如 `6月14日 大学英语四级笔试`，自动识别日期并归类
- **月历总览：** 直观查看每日日程，支持左右切换月份
- **数据持久化：** 自动保存至浏览器本地存储

### 计算器

带括号和百分比运算的科学计算器。

- **基础运算：** 加、减、乘、除、百分比
- **括号支持：** 智能括号匹配
- **退格操作：** 支持光标定位插入和删除
- **键盘快捷键：** `Enter` 计算，`Esc` 清空

### 个人课表

从 Excel 课表文件导入，按周次展示课程安排。

- **Excel 导入：** 上传 .xls/.xlsx 格式课表文件，自动解析
- **周次切换：** 支持第 1-20 周课程查看
- **开学日期设置：** 自定义学期起始日期，自动计算当前周
- **数据持久化：** 课表数据自动保存至浏览器本地存储

## 快速开始

直接打开任意 `.html` 文件即可使用，无需安装任何依赖。

- `todo.html` — 待办事项
- `calculator.html` — 计算器
- `schedule.html` — 个人课表

## 技术栈

- HTML + CSS + JavaScript（纯前端）
- 以 `localStorage` 存储数据
- 课表解析依赖 [SheetJS](https://sheetjs.com/)（xlsx.js）
- 苹果风格 UI（SF Pro 字体、毛玻璃效果、柔和配色）
